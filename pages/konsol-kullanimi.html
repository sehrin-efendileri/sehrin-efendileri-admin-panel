Konsol Kullanımı

Admin komutlarının nasıl yazıldığı ve admin girişinin nasıl yapıldığı hakkında temel rehber.

🎮 Konsol Nedir?

Admin komutlarının büyük bölümü oyun konsolu üzerinden kullanılır. Konsolu açmak için klavyede ESC tuşunun hemen altında bulunan é tuşuna basılır.

Açılan alana komut yazılır ve Enter tuşuna basılır.

🪪 Nick Kontrolü

Admin girişi yapmadan önce nickinizin size verilen admin nicki ile aynı olduğundan emin olun.

Nick değiştirmek için: Options → Multiplayer → Player Name kısmına girin.

🔐 Admin Girişi Nasıl Yapılır?

Konsolu açtıktan sonra aşağıdaki komutu yazın:

setinfo _pw ŞİFRENİZ

Şifreyi yazdıktan sonra Enter tuşuna basın.

⚠ Hatalı Şifre

Şifreyi yanlış yazmanız durumunda sunucudan atılırsınız.

Bunun en yaygın sebepleri:

  • Yanlış şifre yazılması
  • Fazladan boşluk bırakılması
  • Büyük / küçük harf farkı

🔒 Güvenlik Uyarısı

Admin şifrenizi başka oyuncularla paylaşmayın. Şifreniz size özeldir. Başkası tarafından kullanılması durumunda oluşabilecek işlemlerden admin sahibi sorumludur.
